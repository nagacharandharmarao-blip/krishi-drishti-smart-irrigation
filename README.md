# KRISHI-DRISHTI
### AI-Driven Smart Irrigation and Fertigation Platform

## Overview
KRISHI-DRISHTI is a smart agriculture project designed to support efficient irrigation and nutrient management using sensor data and AI-based insights.

## Objectives
- Monitor soil and environmental conditions.
- Collect crop-related data through sensors.
- Display sensor readings on a web dashboard.
- Support informed irrigation and fertigation decisions.
- Promote efficient water and fertilizer usage.
